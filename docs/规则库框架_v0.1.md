> 说明：本文为 D3 框架稿（当时 20 条）。现行规则库已升为 **v0.2 修订稿、共 21 条**（第三轮整改新增 R-NC-003「畜禽类缺检疫合格证明」），以 `data/rules.json` 与页面实际显示为准。
> 状态：AI 起草稿，**未经人工编审，不得直接用于判定**
> 编制流程：AI 起草 → 食品/法律背景老师逐条核对条款号与适用条件 → 编入规则库并注明审核人
> 本文档中所有【待核对】标记 = 条款号/适用条件需人工确认后才能启用
> 规则库版本号规则：v0.x=修订稿（未完成人工编审），v1.0=人工编审后首版，之后每次修订+0.1

## 一、规则元数据结构（规则库 JSON 字段定义）

每条规则固定包含以下字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| id | 规则编号：R-{分类}-{序号} | R-YB-001 |
| name | 规则名称 | 预包装食品无SC证 |
| category | 适用分流线：COM通用 / NC食用农产品 / YB预包装食品 / BJ保健食品 / DL地理标志 | YB |
| platform | 适用范围：GENERAL法规底线 / DOUYIN平台专用 | GENERAL |
| trigger | **触发条件**（硬规则的机器可判定条件，如字段匹配/结构校验/一致性比对） | SC字段为空（预包装线） |
| level | 判定等级：RED红 / YELLOW黄 / GREEN绿 / GRAY灰 | RED |
| engine | 判定引擎：RULE硬规则 / AI-SEMANTIC语义提示 | RULE |
| basis | 法规依据：法规名称+条款号+关键原文摘录 | 《食品安全法》第三十五条 |
| link | 依据链接（国家法规数据库URL） | 待补 |
| action | 整改动作（黄灯必须给可执行动作） | 补充SC证件照片；若无证改为食用农产品线或不播 |
| risk_note | 风险说明（为什么这样判） | 无证生产销售预包装食品违法 |
| updated | 规则更新日期 | 2026-10 |
| source | 规则来源：法规原文/平台官方规则中心 | 《食品安全法》 |

> 2026-10-25 调整：原 `reviewer`（人工编审人）字段已从规则数据中移除，不再要求填写姓名；规则是否核对过，以 `basis.note` 是否标【已核对】为准，人工把关另体现在体检档案的审核人签字与《法规条款核对记录》。

**引擎双轨原则**：
- `RULE` 引擎：规则库直接触发，判定结果**100%可复核**（依据+触发字段写在档案里）；
- `AI-SEMANTIC` 引擎：大模型语义判断"疑似命中某条"，**只提示不判定**，人工终审后生效。

## 二、红黄绿灰定义（判定出口）

| 等级 | 定义 | 出档动作 |
|---|---|---|
| 红 RED | 禁播：存在硬性违法/违规事实 | 生成禁播说明+法条引用，人工签字 |
| 黄 YELLOW | 整改后可播：待核验/缺项/简介表述需修改 | 生成整改单：补什么材料、文案替换表述 |
| 绿 GREEN | 可播：类型正确、资质齐全有效、宣称合规、标签完整、官方核验通过 | 生成体检通过卡，人工签字生效 |
| 灰 GRAY | 信息不足，无法判定 | 生成待补充材料清单（**不误判为违规**） |

## 三、首批规则清单（20条）

### 通用底线（COM，6条）

- **R-COM-001** 疾病治疗/预防功能宣称
  - 触发：宣称文本命中"治疗/治愈/降血压/降血糖/抗癌/包治"等词（RULE词表）+ AI语义确认（SEMANTIC）
  - 等级：RED｜依据：《广告法》第十七条【待核对上下文】、《食品安全法》第七十三条【待核对】
  - 整改：删除功效表述，改为资质范围内的原料或口感描述

- **R-COM-002** 非保健食品宣称保健功能
  - 触发：命中"增强免疫力/改善睡眠/减肥/通便"等保健功能目录词
  - 等级：RED｜依据：《食品安全法》第七十三条【待核对】、《保健食品注册与备案管理办法》【待核对条号】
  - 整改：删除保健功能表述；如产品为保健食品请切换到保健食品线

- **R-COM-003** 绝对化用语
  - 触发：命中"最好/最佳/最强/最优/最低价/最高级/国家级/顶级/全网最低/第一品牌/销量第一/100%有效/绝对"等词表
  - 等级：YELLOW｜依据：《广告法》第九条第（三）项（原文："国家级""最高级""最佳"等用语）
  - 整改：给出合规替换表述（"销量领先"→"深受回购"）；语境例外由人工裁决
  - 词表说明（2026-10-25 收窄）：原裸词"最""第一"会误杀"最后一天""第一场直播""最近发货"，已改为组合词；收窄后可能漏检单独"最"（如"最划算"），由人工审核兜底

- **R-COM-004** 虚构权威背书/荣誉
  - 触发：出现"央视推荐/政府指定/获XX奖"但无对应佐证材料上传
  - 等级：YELLOW｜依据：《广告法》第二十八条（虚假广告）【待核对适用】、《反不正当竞争法》第八条
  - 整改：上传佐证或删除背书表述

- **R-COM-005** 承诺性效果表述（等值于功效承诺）
  - 触发：命中"一周见效/无效退款=功效承诺/告别XX"等组合模式
  - 等级：YELLOW｜依据：《广告法》第二十八条【待核对】
  - 整改：改为体验性描述（"口感软糯"替代"吃了就好"）

- **R-COM-006** 冒用检测报告/报告与产品不符
  - 触发：报告产品名/规格/批号与申报产品比对不一致
  - 等级：RED｜依据：《产品质量法》【待核对条号】、报告"仅对样品负责"原则
  - 整改：提供与申报产品一致的检测报告

### 预包装食品线（YB，6条）

- **R-YB-001** 预包装食品无SC证
  - 触发：YB线且SC字段为空——**生产/自销主体（农户、合作社）判红**；**经销主体（企业经销）降黄**
  - 等级：RED（经销主体按 YELLOW 覆盖）｜依据：《食品安全法》第三十五条（已核对 2026-10-25：生产需许可；仅销售预包装食品不需许可，需备案；SC 属生产企业持有）
  - 整改：补充生产企业 SC 证件；若为委托加工，补充委托方与受托方的对应关系；经销主体核实生产企业持证与仅销售预包装食品备案
  - 口径说明（2026-10-25）：法条明确"仅销售预包装食品的，不需要取得许可"，故经销主体缺 SC 不再直接判红，避免过严

- **R-YB-002** SC号结构异常
  - 触发：非14位 / 前3位类别码不在《食品生产许可分类目录》32类内 / 区划码非法
  - 等级：YELLOW｜依据：《食品生产许可管理办法》【待核对条号】、分类目录（市监总局公告）
  - 整改：提示重拍/核对证号；跳转官方平台人工核验（⚠不声称联网验真，只做结构校验）
  - 说明：SC第14位校验码算法未公开，**不校验最后一位数字正确性**

- **R-YB-003** SC类别码与申报品类不符
  - 触发：类别码对应品类（例：蔬菜制品1601）与申报品类不一致
  - 等级：YELLOW｜依据：分类目录32类对照表
  - 整改：核对品类归属，必要时改为实际工艺品类

- **R-YB-004** 预包装标签缺项
  - 触发：缺名称/配料表/净含量/生产者信息/生产日期/保质期/SC号/贮存条件任一
  - 等级：YELLOW｜依据：GB 7718-2011《预包装食品标签通则》
  - 整改：列出缺项清单；补全后重新体检

- **R-YB-005** 营养标签缺失
  - 触发：YB线且无营养成分表（豁免品类除外：生鲜食品、乙醇≥0.5%饮料等豁免清单内置）
  - 等级：YELLOW｜依据：GB 28050-2011《预包装食品营养标签通则》第7条豁免条款
  - 整改：补营养标签或说明豁免情形

- **R-YB-006** 保质期/日期异常
  - 触发：生产日期晚于当前/保质期格式非法/临期（<1/3保质期）
  - 等级：临期YELLOW、过期RED｜依据：GB 7718-2011、食品安全标准
  - 整改：过期产品直接禁播；临期产品黄灯标注

### 保健食品线（BJ，4条）

- **R-BJ-001** 保健食品无蓝帽子标识
  - 触发：BJ线且包装图未识别到蓝帽子专用标志
  - 等级：RED｜依据：《保健食品管理办法》【待核对】、蓝帽子专用标志规定
  - 整改：请确认为保健食品并补充标志照片

- **R-BJ-002** 无注册号/备案号
  - 触发：缺少"国食健字/卫食健字/食健备"编号
  - 等级：RED｜依据：《保健食品注册与备案管理办法》（2016年，总局令第22号）【待核对条号】
  - 整改：补充编号并跳转特殊食品信息查询平台人工核验

- **R-BJ-003** 宣传超出注册批准功能
  - 触发：宣称功能不在产品注册的24类功能（现27种）范围内【待核对现行目录】
  - 等级：RED｜依据：《食品安全法》第七十八条【待核对】
  - 整改：仅可宣传获批功能与"保健食品不是药物"警示语（GB 16740-2014标签要求）

- **R-BJ-004** 缺少"本品不能代替药物"警示语
  - 触发：包装/页面未出现法定警示语
  - 等级：YELLOW｜依据：GB 16740-2014
  - 整改：在显著位置补充警示语

### 食用农产品线（NC，2条）

- **R-NC-001** 承诺达标合格证缺失
  - 触发：NC线（农户/合作社主体）且未提供承诺达标合格证
  - 等级：YELLOW｜依据：《农产品质量安全法》（2022修订）【条号待核对】
  - 整改：由生产主体开具承诺达标合格证；畜禽类补充检疫合格证明

- **R-NC-002** 食用农产品误标SC
  - 触发：初级农产品（未改变基本性状）却要求SC/误贴预包装食品标签
  - 等级：GRAY→提示分流复核｜依据：《食品安全法》第三十五条豁免条款【待核对】
  - 整改：提示"初级农产品无需SC"，建议回到分流向导确认产品类型（防止误杀）

### 地理标志线（DL，2条）

- **R-DL-001** 未经授权使用地理标志专用标志
  - 触发：出现地理标志标志/名称（烟台苹果等区域公用品牌）但未上传授权证明
  - 等级：RED｜依据：《地理标志专用标志使用管理办法》（国家知识产权局公告第354号）
  - 整改：上传使用许可证明；无授权则删除标志与产区宣称

- **R-DL-002** 产区宣称与SC产地信息不符
  - 触发：宣称"烟台苹果"但SC区划码/产地为其他市
  - 等级：YELLOW｜依据：与R-COM-004同源（虚假宣传）
  - 整改：核对产地后修正宣称
