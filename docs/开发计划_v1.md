| 大刀 | 说明 |
|---|---|
| 1. 零后端 | 规则引擎纯前端本地运行（rules.json 载入页面），不写服务器、不部署、不构建 |

| 5. 功能冻结 | 严格按 MVP 清单，P1 一律不做（进度表末尾留有奖赏槽位） |

## 二、技术方案（极简栈，定稿）

- **形态**：纯 HTML + CSS + JS 单页应用（配 rules.json 规则库文件），双击 index.html 即用
- **规则引擎**：前端硬判定（字段校验/词表匹配/一致性比对/信用代码GB 32100实算）
- **AI增强（可选）**：设置面板填自己的 API Key（DeepSeek 或 GLM 免费额度）
  - 有 Key：语义疑似标记 + 图片OCR多模态识别，回显可编辑字段
  - 无 Key：工具主线（硬规则判定+导出）照常可用 → **评审零配置可独立跑通**
- **交付物形态**：文件夹压缩包 + 运行录屏；线上链接如时间富余加 Cloudflare 静态托管
