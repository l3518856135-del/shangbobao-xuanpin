## 一、《广告法》第九条第（三）项 —— 绝对化用语

| 项 | 内容 |
|---|---|
| 核对结论 | **条款号准确，引用成立** |
| 原文 | 第九条 广告不得有下列情形：……（三）使用"国家级"、"最高级"、"最佳"等用语 |
| 来源 | 中国政府网《中华人民共和国广告法》（2021 修正）；市场监管总局法规库；中国人大网 |
| 对工具的影响 | R-COM-003 依据《广告法》第九条第（三）项，成立 |
| **发现的偏差** | 法条列举的是"国家级""最高级""最佳"**等用语**；当前词表含单字"最""第一"，会把"最后一天""第一场直播"等正常表述判为黄 |
| 处置建议 | ① 依据保留；② 词表收窄为"最好/最佳/最强/最优/最低价/最高级/第一品牌/销量第一"等组合词；③ 保留"语境例外由人工裁决"的处置文案 |
| **处置结果（2026-10-25）** | ✅ 已按建议执行：`wordLists.absolute` 由「最/第一」改为 13 个组合词；R-COM-003 trigger 同步更新；自测第 6 条改为 3 变体反向用例（"最后一天""第一场直播，最近发货"均不命中），全部通过（用例集已扩充至 48 条） |

## 二、《食品安全法》第三十五条 —— 食品生产许可

| 项 | 内容 |
|---|---|
| 核对结论 | **条款号准确，但适用对象需精确区分** |
| 原文 | 国家对食品生产经营实行许可制度。从事食品生产、食品销售、餐饮服务，应当依法取得许可。**但是，销售食用农产品和仅销售预包装食品的，不需要取得许可。仅销售预包装食品的，应当报所在地县级以上地方人民政府食品安全监督管理部门备案。** |
| 来源 | 市场监管总局法规库《中华人民共和国食品安全法》；中国人大网 |
| 对工具的影响 | R-YB-001「预包装食品无 SC 证 → 红」的依据需要补充口径 |
| **发现的偏差** | 法条明确：**仅销售**预包装食品不需要许可（只需备案）。若销售主体选"企业经销"，直接以"无 SC"判红存在过严风险；SC 号是**生产者**的许可，不是销售者的 |
| 处置建议 | ① 规则名与文案改为"无可追溯的 SC 生产许可证编号"；② 依据补 GB 7718-2011 第 4.1.1 条（标签须标食品生产许可证编号）；③ 处置动作补"若为经销主体，SC 应为生产企业持有，需核对代工/委托关系" |
| **处置结果（2026-10-25）** | ✅ 已按"分流判断"改造：`engine.js` 中 YB 线 SC 为空时，**生产/自销主体（农户、合作社）判红，经销主体（企业公司）降黄**并提示"仅销售预包装食品依法不需许可，需备案"；判定等级用 `levelOverride` 覆盖规则默认红；规则 trigger/action/risk_note 同步更新；自测"经销降黄""农户判红"两条验证通过（用例集已扩充至 48 条） |

## 三、GB 7718-2011《预包装食品标签通则》第 4.1.1 条 —— 强制标示内容

| 项 | 内容 |
|---|---|
| 核对结论 | **标准号与条款号准确** |
| 原文要点 | 直接向消费者提供的预包装食品标签应标示：食品名称、配料表、净含量和规格、生产者和（或）经销者的名称/地址/联系方式、生产日期和保质期、贮存条件、食品生产许可证编号、产品标准代号及其他需要标示的内容 |
| 来源 | 国家卫生健康委公开的 GB 7718—2011 标准文本（PDF）；海关总署标准文本副本 |
| 对工具的影响 | R-YB-004 标签缺项判定成立 |
| **发现的偏差** | 当前 trigger 列举 8 项，**缺"产品标准代号"与"联系方式"**，与 4.1.1 的九项不完全对齐 |
| 处置建议 | ① 触发条件补"产品标准代号""联系方式"；② 界面提示文案同步补全；③ 判定仍以人工填写的"标签完整性（完整/缺项）"为准，不在本地做逐项 OCR 判定 |

## 四、GB 28050-2011《预包装食品营养标签通则》第 7 章 —— 豁免情形

| 项 | 内容 |
|---|---|
| 核对结论 | **标准号与豁免章节准确**（准确表述为"第 7 章"，非"第 7 条"） |
| 原文要点 | 下列预包装食品豁免强制标示营养标签：生鲜食品（如包装的生肉、生鱼、生蔬菜和水果、禽蛋等）；乙醇含量 ≥0.5% 的饮料酒类；包装总表面积 ≤100cm² 或最大表面面积 ≤20cm² 的食品；现制现售的食品；包装的饮用水；每日食用量 ≤10g 或 ≤10mL 的食品等 |
| 来源 | 中国政府网公开的 GB 28050—2011 标准文本（PDF）；国家卫生健康委标准文本 |
| 对工具的影响 | R-YB-005「营养标签缺失 → 黄」与界面选项"属豁免品类"成立 |
| **发现的偏差** | 依据备注写"第 7 条"，规范表述应为"第 7 章"；豁免清单未提示"生鲜食品"这一最常见情形 |
| 处置建议 | ① 备注改"第 7 章"；② 界面"属豁免品类"提示补"生鲜/小面积包装/现制现售/饮用水/日食用量≤10g"等常见情形 |
