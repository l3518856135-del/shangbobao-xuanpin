## 十、复现步骤

1. 打开 `index.html`
2. 分流：预包装食品 → 企业经销 → 抖音
3. 按第三节表格填写字段（标签完整性选"缺项"）
4. 点击「证据核验」→ 点击「规则判定」→ 应显示「黄·整改」
5. 点击判定区出现的「生成整改单」→ 可打印/导出 PDF
6. 进入人工审核 → 逐条裁决「确认违规」→ 结论「整改后上播」→ 签字生效
7. 点击「导出档案（第 6 步）」→ 得到第八节档案全文

## 十一、本轮新增/变更

| 变更 | 说明 |
|---|---|
| 新增「生成整改单」功能 | 仅在「黄·整改」态出现；红态为禁播说明、绿/灰态无需整改，避免误用 |
| 整改单内容 | 基本信息 + 问题清单（含命中词、风险说明、整改要求、法规依据）+ 需补充材料 + 整改期限（7 个自然日）+ 签收栏 + 免责声明 |
| 打印分流 | 档案与整改单各自独立打印（`body.print-archive` / `body.print-rectify`），修复原先只能打印档案的问题 |
| 口径约束 | 整改单明确"取得绿·可播判定后方可上播"，形成闭环；依据条款号保留【待核对】提示，不生成新法条 |
| 文案调整（2026-10-25 评审修正） | 原文案含"一周见效，润喉止咳效果好"。引擎补入医疗用语与承诺性效果词表后，该表述应判**红**（R-COM-001 + R-COM-005），本案例将不再是黄态。为保持"黄·整改"演示样本，文案改为"全网最低价，顶级食材，好吃不贵"，仅保留绝对化用语；功效类红灯样本由案例三承担 |
