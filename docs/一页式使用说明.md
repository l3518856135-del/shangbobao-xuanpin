# 上播前·选品体检 · 一页式使用说明

**一句话**：上播前 3 分钟，查清这个品能不能播、缺什么、怎么改。

## 一、打开方式

双击 `index.html` 即可，**无需安装、无需联网**（建议 Chrome / Edge）。资料只保存在本机浏览器，不上传云端。

## 二、六步操作

| 步骤 | 你要做什么 | 你会看到什么 |
|---|---|---|
| 1 分流 | 选产品类型、销售主体、带货平台 | 本次适用的规则线 |
| 2 录入 | 填产品信息、资质、直播文案；可上传包装图自动识别，没配密钥就直接手填 | 表单自动存草稿 |
| 3 核验 | 点「证据核验」 | 通过 / 需修正 / 人工核对 |
| 4 判定 | 点「规则判定」 | 红黄绿灰 + 命中规则 + 待补充清单 |
| 5 审核 | 逐条裁决，选审核结论，填审核人、日期，点「签字生效」 | 已签字生效 |
| 6 导出 | 点「导出档案（第 6 步）」；黄态可先点「生成整改单」 | 可打印 / 另存 PDF |

## 三、四种结果怎么处置

| 结果 | 含义 | 你该做什么 |
|---|---|---|
| 红·禁播 | 存在硬性违法/违规事实 | 不能播，按明细处理（不提供整改单） |
| 黄·整改 | 整改后可播 | 点「生成整改单」，7 日内改完再来体检 |
| 绿·可播 | 资质齐全有效、宣称合规 | 出档案，可安排上播 |
| 灰·信息不足 | 资料不全，**不判违规** | 按清单补材料，补完重新判定 |

## 四、三条硬提醒

1. SC 号、统一社会信用代码、报告编号请照证件原样填写；工具只做结构校验，**不联网验真**。
2. 判定只是提示，**必须人工逐条裁决并签字**才生效，签字后才写入档案。
3. 档案含企业信息时，打印前勾选「脱敏显示」。

## 五、常见问题

- **点了没反应？** 确认分流三项都已选好，再点「进入资料录入」。
- **想存 PDF？** 档案页点「打印 / 导出 PDF」，目标打印机选「另存为 PDF」。
- **换电脑数据没了？** 档案存在本机浏览器，换设备不互通，请先导出保存。
- **想先看效果？** 点顶部「演示模式」，一键载入示例数据跑完整流程。

**使用边界**：本工具仅供内部决策参考，不构成法律意见；法规依据来自人工编审的规则库，条款号未核对项标【待核对】。
